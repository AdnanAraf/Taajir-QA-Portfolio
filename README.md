This project showcases comprehensive Software Quality Assurance (SQA) activities, manual testing documentation, API testing, bug reports, and test execution for the Taajir Inventory Management System.

***Project Overview*** : 

**Project Name** : Taajir(Inventory Management System)

**Project Type** : Cross-Platform Application (Web & Mobile)

**Website**      : https://taajir.app/login

**Testing Focus**: Manual Testing, Functional Testing, API Testing, and Regression Testing.

**Testing Tools**: Postman, Jira

**Bug Tracking & Management**: Jira.

**Testing Activities**

1. Created and executed test cases and test scenarios for different application modules.

2. Performed manual and functional testing to verify application behavior.

3. Conducted API testing using Postman.

4. Identified, documented, and reported software defects with clear reproduction steps.

5. Performed retesting and regression testing after bug fixes.

6. Verified payment transactions, customer and supplier ledgers, inventory operations, and financial reports.

7. Used Jira to track defects and manage testing activities.
